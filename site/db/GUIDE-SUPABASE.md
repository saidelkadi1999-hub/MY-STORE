# CÂLINE × Supabase — دليل الربط (المرحلة 1)

هاد المرحلة كتصاوب **قاعدة البيانات الكاملة** وكتربط الموقع بها. الفيديوهات/الدفع/الإحصائيات غادي تجي فمراحل بعد.

## الملفات
- `caline-schema.sql` → بنية قاعدة البيانات (8 جداول + علاقات + أمان RLS).
- `caline-seed.sql` → البيانات الأولية (12 فئة + 21 منتوج من المتجر الحالي).
- الموقع `index.html` → مربوط مسبقاً بـSupabase (كيخدم بالبيانات المدمجة حتى تعمّر الإعدادات).

## الخطوات

### 1) صاوب حساب ومشروع Supabase (مجّاني)
1. سير لـ https://supabase.com → **Start your project** → دخل بـGitHub/Email.
2. **New project** → عطيه اسم (CALINE) + باسوورد لقاعدة البيانات (سجّلو) + اختار région (Europe).
3. تسنّى شي دقيقة حتى يتفعّل.

### 2) شغّل الـSQL
1. فالمشروع: **SQL Editor** (القائمة اليسرى) → **New query**.
2. الصق محتوى **`caline-schema.sql`** كامل → **Run**. (خاصو يكمل بلا أخطاء.)
3. **New query** آخر → الصق **`caline-seed.sql`** → **Run**.
4. تأكد: **Table Editor** → غادي تلقى `products` فيه 21 منتوج، و`categories` فيه 12.

### 3) جيب المفاتيح
**Project Settings** (⚙️ تحت) → **API** → نسخ:
- **Project URL** (بحال `https://xxxx.supabase.co`)
- **anon public** key (مفتاح طويل)

> ⚠️ ماتستعملش `service_role` key فالموقع — هادا سرّي للسيرفر فقط (مرحلة الدفع).

### 4) عمّر الإعدادات فالموقع
حلّ `index.html`، قلّب على هاد البلوك فوق (قرب راس الملف):

```js
window.CALINE_SUPABASE = {
  url:     "",   // ← حط هنا Project URL
  anonKey: ""    // ← حط هنا anon public key
};
```

عمّرهم بالقيم ديالك، حفظ، ونشر على Netlify.

### 5) جرّب
- حلّ المتجر، افتح **Console** ديال المتصفح (F12).
- خاصك تشوف: `CÂLINE : catalogue chargé depuis Supabase (21 produits).`
- باش تتأكد فعلاً كيقرا من قاعدة البيانات: بدّل ثمن منتوج فـSupabase (Table Editor)، عاود حمّل الصفحة → الثمن الجديد كيبان بلا ما تبني الموقع من جديد. 🎉

## ملاحظات تقنية
- **الأمان (RLS):** القراءة العامة مسموحة فقط للكاطالوغ (products, categories, settings, الأفضليات المعتمدة). الطلبات/العملاء/الكوبونات **مقفولين** — غادي يتعاملو معاهم عبر دالة سيرفر (service_role) فمرحلة Stripe.
- **fallback:** إلا بقاو الحقلين فاضيين، أو طاح الاتصال، الموقع كيخدم بالبيانات المدمجة بلا انقطاع.
- **الصور:** حالياً الصور كتجي من مجلد `images/` ديال الموقع (نفس المسارات فقاعدة البيانات). فمرحلة لاحقة نقدرو ننقلوهم لـSupabase Storage.
- **العلاقات:** products.category_id → categories.id · order_items → orders/products · reviews → products/customers · orders → customers/coupons.
