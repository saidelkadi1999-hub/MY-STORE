# CÂLINE — لوحة الإدارة (المرحلة 2)

لوحة تحكّم فاخرة محمية بتسجيل دخول، كتعرض **بيانات Supabase حقيقية**:
إجمالي المبيعات · الطلبات · العملاء · الزوار · الأكثر مبيعاً · آخر الطلبات · الإيرادات اليومية والشهرية.

## التركيب (مرة وحدة)

### 1) شغّل الـSQL ديال الأدمن
Supabase → **SQL Editor** → New query → الصق **`caline-admin-schema.sql`** → **Run**.
(كيزيد: جدول `admins`، جدول `visits`، دالة `is_admin()`، سياسات الأمان، ودوال الإحصائيات.)

### 2) صاوب حساب الأدمن
1. Supabase → **Authentication** → **Users** → **Add user** → دخل email + mot de passe → Create.
2. نسخ **User UID** ديال هاد المستخدم.
3. SQL Editor → شغّل (بدّل القيم):
   ```sql
   insert into admins(user_id, email)
   values ('UID-ديالك-هنا', 'email-ديالك')
   on conflict (user_id) do nothing;
   ```

### 3) عمّر مفاتيح Supabase فـ admin.html
فوق `admin.html` كاين:
```js
window.CALINE_SUPABASE = { url:"", anonKey:"" };
```
عمّرهم بنفس القيم ديال المتجر (Project URL + anon key)، حفظ.

### 4) انشر
حط `admin.html` مع الموقع على Netlify → كيوّلي متاح على:
`https://ton-site.netlify.app/admin.html`

## الاستعمال
- دخل بالـemail والباسوورد → تشوف اللوحة.
- إلا دخل شي حساب ماشي أدمن → كيرفض الدخول تلقائياً (`Accès non autorisé`).
- كل الأرقام **حقيقية** من قاعدة البيانات:
  - **الزوار** كيتسجّلو أوتوماتيكياً منين الناس كيزورو المتجر (جدول `visits`).
  - **المبيعات/الطلبات/العملاء/الأكثر مبيعاً/آخر الطلبات** كيجيو من الطلبات الحقيقية.

> ملاحظة: المتجر مازال جديد، فالأرقام كتبدا بـ0 وكتزيد بصح منين كيجيو طلبات وزوار حقيقيين — هادي بيانات حقيقية ماشي تجريبية. منين نربطو Stripe (مرحلة جاية) الطلبات كتبدا تتسجّل وكتبان هنا مباشرة.

## الأمان
- اللوحة محمية بـSupabase Auth + سياسات RLS: حتى واحد ماقادر يقرا الطلبات/العملاء إلا كان مسجّل فجدول `admins`.
- دوال الإحصائيات كلها كتتحقق `is_admin()` قبل ترجّع شي بيانات.
- ماتنشرش مفتاح `service_role` — اللوحة كتخدم بـ`anon` + جلسة مسجّلة فقط.
