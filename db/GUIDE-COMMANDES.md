# CÂLINE — إدارة الطلبات (المرحلة 4)

صفحة `admin-orders.html` كتعرض كل الطلبات وتفاصيلها، وكتخليك تبدّل الحالة — وكل تغيير كيتحفظ **مباشرة فـSupabase**.

## التركيب (مرة وحدة)
1. Supabase → **SQL Editor** → شغّل **`caline-orders-admin-schema.sql`** (كيزيد `phone` و`payment_method`).
2. عمّر مفاتيح Supabase فوق `admin-orders.html` (نفس url + anonKey).
3. انشر → متاحة على `/admin-orders.html` (وكاين رابط ليها من لوحة التحكّم وصفحة المنتجات).

## واش كتشوف
- 📋 **جميع الطلبات** فجدول (رقم، عميل، إيميل، حالة، مجموع، تاريخ).
- 🔎 فلترة حسب الحالة (chips فوق) + بحث (رقم/إيميل/اسم).
- كليكي على شي طلب → **درج التفاصيل**:
  - 👤 اسم العميل · 📧 الإيميل · 📞 الهاتف
  - 🏠 عنوان التوصيل الكامل
  - 🛍️ المنتجات المطلوبة (الاسم، اللون/المقاس، الكمية × الثمن = المجموع)
  - 💳 طريقة الدفع + الكوبون + التفاصيل (sous-total، livraison، remise، total)

## تغيير الحالة
فالدرج، فقسم **Statut**، اختار من اللائحة:
`En attente (pending)` · `Payée (paid)` · `En cours (processing)` · `Expédiée (shipped)` · `Livrée (delivered)` · `Annulée (cancelled)`
ثم **Enregistrer** → كيتحفظ فقاعدة البيانات وكيتحدّث الجدول فوراً.

## ملاحظات
- المتجر مازال جديد فالطلبات كتبدا فارغة — كتبدا تظهر منين يبدا الناس يخلّصو (بعد ربط **Stripe** فالمرحلة الجاية).
- باش تجرّب الواجهة دابا: كاين بلوك **اختياري** فآخر `caline-orders-admin-schema.sql` (مكتوب كـcommentaire) كيزيد طلب تجريبي — حيّد `--` وشغّلو، ومن بعد تقدر تمسحو.
- الحماية: حتى واحد ماقادر يشوف ولا يبدّل الطلبات إلا كان أدمن (RLS + is_admin).
